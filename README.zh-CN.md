# Bangumi Manager

[English](README.md) · [简体中文](README.zh-CN.md)

用于整理电影、电视剧和音乐的 Windows 桌面应用，可配合 Jellyfin、Kodi、Emby 等媒体软件使用。先人工核对作品与季集关联，再将文件复制、移动、链接、替换或重命名到本地媒体库。

## 功能

- 通过 TMDB、Bangumi 查询作品，通过 MusicBrainz 查询音乐发行版本、碟片与音轨。
- 从已有 NFO 文件导入数据库关联；切换 TMDB 剧集组，并在编号变化后重命名入库资源。
- 按顺序、名称或数字批量匹配文件，支持包含多集内容的文件。
- 按扩展名、大小、分辨率、码率、编码筛选资源，使用 ffprobe 按需探测媒体信息。
- 比较替代文件、备份旧版本，并在确认后清理备份。转码由外部工具完成。
- 通过任务队列执行文件操作，提供校验、进度、恢复检查点和耗时诊断。
- 支持简体中文和英文界面，界面语言与资料查询语言独立。

## 环境与安装

需要 Windows 10 或更新版本，以及 Microsoft Edge WebView2 Runtime。目前支持 Windows 构建，不提供 macOS 或 Linux 发行版。网络共享使用当前 Windows 账户的访问权限。

可在 [Releases](https://github.com/zhyupe/bangumi-manager/releases) 查看已发布版本，或按照[构建说明](CONTRIBUTING.md)从源码构建。更新前先关闭旧版程序。分发便携版时，请保留 `LICENSE` 和 `THIRD_PARTY_NOTICES.txt`。

媒体探测需要自行安装 ffprobe，将其加入 `PATH` 或在「设置」中选择可执行文件。普通目录扫描不依赖 ffprobe。TMDB 需要自己的 API Read Access Token；Bangumi 和 MusicBrainz 的公开查询无需密钥。

## 开始使用

1. 在「设置」中选择输出、附加文件和备份目录。附加文件与备份应位于媒体库扫描目录之外。需要使用 TMDB 时填写 Token。
2. 打开「整理」，扫描目录或拖入文件，选中同一作品的文件。选择已入库作品，或通过「添加作品」搜索资料源。
3. 选择季度或碟片，应用批量匹配，核对文件对应关系及缺少的集数。电影以影片展示，音乐以碟片和音轨展示。
4. 创建任务，检查目标路径与冲突，再确认执行。默认使用复制，保留源文件。
5. 在「剧集」管理作品关联，在「资源」检查或替换文件，在「任务」查看进度、处理错误和恢复中断操作。

界面默认跟随系统语言。在「设置 → 界面语言」可即时切换，并在本机记忆选择；这不会更改 TMDB 查询语言、作品名称、文件路径或命名规则。

NFO 导入、剧集组、重命名、替换、备份和排错操作详见[使用指南](docs/user-guide.zh-CN.md)。

## CUE 音乐入库

自行安装 FFmpeg 和 FFprobe，在「设置」中选择包含两者的目录即可一次配置；不同目录可展开「分别指定可执行文件」。使用「检查 FFmpeg」确认可用性。应用不捆绑 FFmpeg；路径留空时，优先使用 ffprobe 同目录中的 FFmpeg，否则查找 `PATH` 中的 `ffmpeg`。

在「整理」添加 `.cue` 文件，或扫描目录后点击「解析 CUE」。先核对引用音源；无法识别文本编码时，可选择 GB18030 或 Shift-JIS。目录外的引用必须手动选择文件。随后选择 MusicBrainz 的具体发行版本和碟片，或使用 CUE 信息建立本地专辑。曲目数不一致时需手动匹配。在整理页侧边栏选择一个 CUE 后进入对话框核对，创建任务后关闭对话框。

提交前检查曲名、表演者、最终路径、警告和已有文件的处理方式。无损 FLAC、APE、整数 PCM WAV/AIFF、ALAC 音源输出 FLAC，保留采样率、有效位深和声道。MP3、AAC 保留原编码，预览会显示按编码帧调整后的切点偏移。若音频包或独立解码校验存在差异（例如编码延迟、帧依赖），任务停止，不提交输出；此时请使用外部工具拆分。不支持 DSD、浮点音频、数据轨和需要预加重处理的音源。

已存储的轨前间隙归前一曲，首曲之前的音频保留在首曲开头；仅声明的间隙不会补静音。最后一步可选择保留原始 CUE 与音源（默认）、永久删除或移动到配置的备份目录。删除与备份需要明确确认，仅在全部曲目成功入库并校验后执行；跳过曲目时保留原文件，文件变化或其他未完成任务仍引用原件时停止处理。原文件备份可在「资源」中管理，删除已完成任务后仍可查询。此选项独立于默认复制、移动或链接设置。全部选中音轨先暂存并校验，再提交到资料库。可在「任务」暂停、继续；完成前请保留临时文件与恢复记录。原始 CUE 不会作为新分轨文件的播放索引复制入库。

## 文件操作与恢复

执行前请核对任务。移动会在完成必要校验后移除源文件；硬链接共享文件内容，软链接则依赖源路径及播放器的访问权限。

替换只处理明确选中的旧文件。备份默认保留，只有主动清理才会删除，且不可恢复。中断任务会保留恢复信息，尤其是尚未完成的重命名任务：应保留临时文件和检查点，再从「任务」继续。重新打开应用不会自动继续队列。

资料库扫描只读取文件信息，离线目录保留上次结果。程序会生成 NFO；请在媒体软件中配置本地元数据读取方式，并保持季集排序一致。命名、NFO 字段和分段播放的支持因软件而异，媒体库扫描与播放由所用媒体软件管理。一般媒体转码仍使用外部工具；CUE 拆轨会为新生成的音轨写入标签，不修改原始音源的标签。

## 本地数据与隐私

应用数据位于 `%LOCALAPPDATA%\io.github.zhyupe.bangumi-manager`。升级时会沿用已有应用数据目录，实际位置可在设置页查看。备份此目录前请关闭程序。设置环境变量 `BANGUMI_MANAGER_DATA_DIR` 为独立的绝对路径，可使用隔离的数据目录。

资料搜索与图片请求会访问相应资料源。TMDB Token 保存在本地设置中；MusicBrainz 联系地址会随请求标识发送，可在设置中修改。程序未配置分析统计服务。

在「设置 → 耗时与日志」查看耗时记录。日志不记录 Token、搜索词、响应正文及本地媒体路径；导出的任务计划、截图和其他诊断资料可能包含路径或元数据，分享前请检查并脱敏。更多说明见[安全与隐私](SECURITY.md)。
