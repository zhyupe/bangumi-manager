# 使用指南

[English](user-guide.md) · [简体中文](user-guide.zh-CN.md)

## 作品与集数匹配

添加电影和电视剧默认使用 TMDB。可以按名称搜索，也可粘贴电影或剧集链接来明确类型。输入数字 ID 时先按当前类型读取，只有主条目不存在时才尝试另一类型；鉴权或连接失败会直接显示错误。

添加窗口左侧用于搜索和选择条目，右侧用于查看详情和确认入库，两侧可独立滚动；窄窗口下改为上下排列。添加成功后窗口保持打开，搜索结果和关联条目仍可使用，便于继续添加其他作品或季度。本次已添加的条目会显示标记，不能重复提交；失败的条目可重试。全部添加完成后关闭窗口即可。切换 TMDB 剧集组仍在确认成功后关闭窗口。

Bangumi 不同季度的条目可以关联到同一个本地作品，季号需人工确认。特别篇需要明确启用并指定编号。同一集的多个资料源不会重复计入已拥有集数。

搜索结果会标记已入库条目。选择后，按资料源、源类型和 ID 自动关联已有本地条目，也支持从 NFO 导入的数据库 ID。「更新本地目录信息」在确认后更新原条目，保留本地主目录名、入库类型、季度映射和已选 TMDB 剧集组。不同条目仍可手动关联为新季度。

音乐请选择专辑类型及资料源。MusicBrainz 返回具体发行版本，可根据艺术家、日期、地区、介质和音轨选择正确版本；发行组链接会列出版本，不会自动导入任意版本。多碟编号会保留。请求遵循服务端限流，未命中缓存时可能需要等待。

在「整理」中先选中文件，再应用批量匹配。数字匹配支持 `sampleQe01.ts`、`Fictional.Series.S01E01.mkv` 等形式，请核对数字位置与偏移。季度下拉框下方的集数摘要可帮助比较已启用集数与当前匹配情况。「包含集数」指定一个文件实际覆盖的集数：先选开始集，再选择最后包含的集数，不会合并或拆分视频；有歧义的名称保留为未匹配，供人工处理。

数字匹配优先采用 `S01E09` 等季集标记和独立方括号数字，再考虑标题中的数字。例如 `[Fictional Journey 2][09][720P].mp4` 默认匹配第 9 集；其他提取到的数字仍可在数字位置下拉框中选择。优先集号不存在时保留为未匹配，不会回退到标题数字。

在作品的季度页中，将文件拖到集数行，会直接在当前页面预览变更。可以继续添加其他集、移除待提交文件，并核对目标路径、字幕、备份及冲突。「提交并查看」创建任务并打开任务页；「提交并执行」将任务加入执行队列，作品页面保持打开。预览后若文件、关联或命名设置发生变化，需要重新预览并核对。

作品详情中的「额外文件」支持拖入文件或目录，也可通过按钮选择。导入沿用同一待提交预览和提交操作，遵循下文的附加文件目录规则，不计入已拥有集数。

媒体旁若有同名 NFO，且包含支持的数据库 ID，可通过 NFO 同步入口预览并导入关联。NFO 内容仅作为元数据输入，不作为执行命令的指令。

目录名完整匹配 `bonus`、`extra`、`extras`、`cd`、`cds`、`scan` 或 `scans` 时（不区分大小写），扫描会将目录内文件识别为附加文件。选中文件与作品后自动匹配为附加文件，也可手动修改；批量匹配时这些文件不占用集数或曲目编号。已有扫描结果需重新扫描目录才能识别。

整理到附加文件目录时保留子目录结构，仅去掉最外层识别目录为 `bonus`、`extra` 或 `extras` 的包装层。例如 `Bonus/Disc 1/cover.jpg` 保存为 `<附加目录>/<作品>/Disc 1/cover.jpg`，`Scans/Book/01.jpg` 保存为 `<附加目录>/<作品>/Scans/Book/01.jpg`。内部字幕也会作为独立附加文件显示，请一并选中。若最终路径仍重名，任务预览会提示冲突，需要处理后再执行。

SRT、ASS、SSA、SUB、IDX、VTT 字幕可以单独加入「整理」，使用现有的手动、数字、顺序或名称匹配。请先将对应电影或剧集的视频入库；字幕沿用视频实际目录和主文件名，保留末尾的两位或三位字母语言标记及可选地区或文字后缀，例如 `.en`、`.chs`、`.cht`、`.eng`、`.zh-Hans`，也支持用 `&` 连接多个语言标记，例如 `.chs&jpn.ass`。`.01` 等纯数字结尾仍作为集号处理。顺序匹配按每个目录中的语言和格式分别计数；仅选中字幕时，季度摘要显示字幕匹配情况。

任务预览会展示对应视频和字幕目标路径。视频缺失或变化、存在多个版本、仅匹配合并集的一部分时会阻止导入。已有字幕需明确选择替换，并先备份；视频和 NFO 保留原状。与待整理视频同名的字幕仍会自动跟随视频任务处理。

误添加的作品可在「剧集」中打开作品详情，选择「删除作品」。已下载的集数资料不影响删除；存在关联资源（包括离线文件）、已绑定目录、未完成任务、文件恢复记录或其他作品的关联时会阻止删除。确认后移除作品及其待匹配记录，源文件、媒体、字幕、备份和已结束的任务记录均保留。需要时可重新从数据源添加。

## 分段电影和剧集

一个电影或一集拆成多个文件时，将所有文件匹配到同一个电影或同一集，再在「分段」中分别选择 Part 1、Part 2 等编号（最多 8 段）。这与一个文件包含多集不同，不能同时设置多集范围。明确的 `Part1`、`Part2` 等标记会自动识别，分段数字不会作为集号；同名分段在顺序匹配时也共用一个集号。

电影的 `Fictional Feature - 01.mkv`、`Fictional Feature - 02.mkv` 这类文件，只有在同目录、相同主名称且编号从 01 连续出现时才自动识别。缺少明确标记或编号不连续时请手动设置。对于一个集名由斜杠分隔的两个章节，名称匹配可按明确的 Part 编号比较相应章节标题；有歧义时仍需手动选择集数。

入库名称添加 ` - part1` 等后缀，同名字幕跟随对应 part；单独导入字幕时也要选择对应 part，且该视频必须已存在。季度页支持一次拖入多个明确编号的分段文件，并在当前页预览。重命名保留分段编号；替换只处理所选 part。重复编号和完整文件与分段文件混用会阻止执行，避免覆盖其他部分。

集数统计按集去重，不能据此判断所有 part 是否齐全；请同时核对分段文件列表。分段命名与播放支持取决于所用媒体软件和客户端。批量整理前，请核对其对电影、剧集分段以及封装、音轨和字幕的要求。

## TMDB 剧集组与重命名

打开电视剧详情，选择「切换 TMDB 剧集组」并加载可选组。核对组名、类型、集数和编号预览；之后也可以切回 TMDB 默认季度。后续同步沿用选中的组。

切换剧集组只更新关联，不立即修改媒体文件名。未收录的旧集数保留并停用。存在未结束任务、关联不明确或合并集不再连续等情况时会阻止切换，需要先解决提示中的冲突。

保存编号后，可使用作品详情的「重命名入库资源」、季度内的重命名入口，或「资源」页的选中资源操作。创建和执行任务前核对原路径、新路径与 NFO 备份。实际作品目录保留；同名字幕和单文件 NFO 随媒体改名，共享 NFO 备份后原位更新。

目标位置的未选中文件不会被隐式覆盖。需要交换文件名时，任务先暂存本批文件再提交目标路径。中断后应保留临时文件与恢复记录，先继续任务，再修改关联或执行后续操作。

## 资源检查与替换

在「资源 → 媒体文件」扫描已注册资料库。可按作品、文件名、路径搜索，并组合扩展名、编码、大小、分辨率和总码率筛选。未知值始终排在末尾，也可单独筛选。离线目录保留上次结果。

扫描不会自动运行 ffprobe。需主动探测选中项或全部筛选结果；后台最多同时探测两个文件，支持取消与失败重试。详情区分总码率和视频码率，按大小与时长计算的估算值会明确标注。

资源行可「选择替代文件」，也可选中资源后扫描候选。电影和季度详情提供相同入口。扫描使用原文件所在的实际目录，优先匹配同主文件名，再匹配明确的作品与季集范围。候选全部列出，由你选择。未关联文件需先关联作品。

比较时核对时长、分辨率、编码、大小、音轨、字幕、最终路径、备份位置和文件操作。新文件允许更大，分辨率增加本身不代表画质提升。时长差超过五秒与原时长 1% 中的较大值、分辨率下降、轨道减少或无法探测时，需要逐项确认。

替换只处理明确选中的旧版本。保留旧目录与主文件名，扩展名跟随新文件。库外文件使用设置中的整理方式；已有库内文件可以移动或原位接纳。新文件自身不会被加入旧版本备份。

没有新外置字幕时保留原字幕；覆盖同路径字幕需要明确选择，替换后请核对时间轴。共享 NFO 备份后原位更新。失败会暂停队列，并保留备份和恢复检查点。

TS、M2TS 是封装格式，不代表画质。仅换封装不一定明显减小体积；如需转码，请使用外部工具，比较画质及轨道兼容性后再替换原文件。

## 备份与文件操作

在「资源 → 旧版本备份」按文件或任务选择清理。确认界面列出确切路径及逻辑字节数。只有已登记、未被修改、对应任务完整成功且新资源可验证的备份才能删除；失败或状态不明确的任务受到保护。删除已完成任务记录不会删除独立登记的备份。

清理不可恢复，默认不自动执行。逻辑文件大小不等于磁盘实际释放空间，硬链接、压缩、去重和存储快照都可能影响物理占用。

根据存储环境选择复制、移动、硬链接或软链接。适用时 SMB 操作使用受支持的服务端机制，失败会显示错误，不会静默丢弃必要校验。请使用运行应用的同一 Windows 账户检查共享权限。路径旁的文件管理器按钮可打开所在位置；尚未生成的目标打开最近存在的父目录。

## 媒体库兼容与排错

请在所用媒体软件中配置扫描和本地 NFO 读取方式，电视剧排序应与选中的剧集组一致。支持的 NFO 字段、命名规则、音轨、字幕和客户端能力因软件而异。在整个资料库采用新编码前，应先在实际客户端验证；本程序不内置转码，也不控制媒体服务器或播放器。

打开「设置 → 耗时与日志」，复现慢操作后刷新统计，查看进行中的操作、耗时和失败情况。日志位于应用数据目录的 `logs/performance.jsonl`，保留轮转历史。重启后统计重新累计，日志文件仍保留。

搜索缓慢时可比较资料源、网络请求和数据库等待的耗时。整理文件期间仍能查询远程资料；保存关联变更可能需要等待任务停止。队列失败后，检查任务错误、修正原因，按需重试失败任务，再明确继续队列。分享诊断资料前请阅读[安全与隐私](../SECURITY.md)。
